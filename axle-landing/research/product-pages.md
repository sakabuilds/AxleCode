# Product pages research

Researched with Kroma on 2026-10-13 before writing the rebuild UI. Each page received separate UI inspiration and component searches; the footer received graphic and component searches. Queries targeted Awwwards, Mobbin, Dribbble, Magic UI, Aceternity UI, shadcn/ui, and Radix. Some image results widened outside the requested sources; those irrelevant results are not design evidence. Targeted Kroma web searches supplied the Awwwards, Mobbin, and Radix references below after a temporary network failure on image follow-ups.

## Product

- [Linear, Awwwards](https://www.awwwards.com/inspiration/linear-the-issue-tracking-tool-youll-enjoy-using): borrow the restrained product-led hierarchy, dark surfaces, and highly legible interface framing.
- [Linear palette and UIs, Mobbin](https://mobbin.com/colors/brand/linear): use near-black and grey hierarchy; remove the source's indigo to honor the monochrome brand.
- [Sticky Scroll Reveal, Aceternity](https://ui.aceternity.com/components/sticky-scroll-reveal): borrow a persistent mockup paired with numbered short steps. Use native sticky positioning, small parallax, and reduced-motion fallback.
- [Feature sections, Aceternity](https://ui.aceternity.com/feature-section): separate the steps into read, plan, edit, and verify, with a clear example interface for each.

## Features

- [Dark Mode Bento Card UI for Developer Platform, Dribbble](https://dribbble.com/shots/27484031-Dark-Mode-Bento-Card-UI-for-Developer-Platform): borrow varied card spans and tight interface snippets, not decorative charts or unverified data.
- [Features section bento grid, Dribbble](https://dribbble.com/shots/27705956-Features-section-bento-grid): borrow the balance of feature copy and a small, concrete demonstration.
- [Bento Grid, Magic UI](https://magicui.design/docs/components/bento-grid): responsive spans and shared card composition.
- [Bento grid construction, Aceternity](https://ui.aceternity.com/blog/how-to-create-a-bento-grid-with-tailwindcss-nextjs-and-framer-motion): reusable card structure; style locally with hairlines and one-time restrained reveals.

## Changelog

- [Version History with Activity Timeline, Dribbble](https://dribbble.com/shots/26274293-Version-History-with-Activity-Timeline): narrow date rail, generous article body, compact tags.
- [Changelog template, Magic UI](https://magicui.design/docs/templates/changelog): chronological layout and readable entry spacing.
- [shadcn/ui changelog](https://ui.shadcn.com/docs/changelog): explicit dates and concrete behavior changes, without invented performance numbers.
- [Aceternity changelog](https://ui.aceternity.com/changelog): compact per-release summaries and separated lists.

## Company

- [Insoft careers page, Dribbble](https://dribbble.com/shots/7085463-Insoft-Careers-page-in-dark): quiet typography and distinct careers/contact bands.
- [Non-Linear Studio, Awwwards](https://www.awwwards.com/sites/non-linear-studio): editorial scale and whitespace for a principles-led company story.
- [Radix Accordion](https://www.radix-ui.com/primitives/docs/components/accordion): keyboard and aria patterns for any expandable principles or careers FAQ.
- [shadcn/ui](https://ui.shadcn.com/docs): low-level accessible primitives, locally styled. Use no invented people, team counts, office addresses, hiring listings, or endorsements.

## Shared footer

- [Footer.design](https://footer.design): compact grouped sitemap, clear site-ending rule, prominent but quiet wordmark.
- [Footer logo references, Dribbble](https://dribbble.com/search/footer-logo): wordmark as composition rather than oversized decoration.
- [Website footer guidance, Magic UI](https://magicui.design/blog/website-footer): concise navigation groups with useful destinations.
- [shadcn sidebar](https://ui.shadcn.com/docs/components/sidebar): consistent link spacing and visible focus treatment; use normal semantic footer/navigation markup.

## Product truth from repository

The root README verifies a local desktop coding app for Windows, macOS, and Linux; own provider API keys; file read/edit/search, terminal and Git; approval controls and read-only Plan mode; project folders and WSL; persistent local threads; local-network or Tailscale remote access; OpenAI/Codex, Anthropic/Claude, Google/Gemini, and OpenRouter support. Downloads are at https://github.com/thatcreativetayo/AxleCode/releases. The rebuild uses the requested Axle marketing brand while retaining these real product behaviors.

The old marketing content includes unsupported testimonials, team statistics, offices, release numbers, performance benchmarks, pricing promises, and hiring listings. Treat those as draft marketing copy, not evidence; remove or replace with verifiable repository facts and neutral contact/contribution links.
